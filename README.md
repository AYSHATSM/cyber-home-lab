# Cybersecurity Home Lab

## Overview
A local cybersecurity lab for learning web application
security, network analysis, and defensive security.

## Objectives
- Build a safe, isolated testing environment.
- Practice authorized security assessments.
- Document findings and remediation.
- Develop practical cybersecurity engineering skills.

## Environment
- Host: Windows
- Security environment: Kali Linux
- Practice target: OWASP Juice Shop
- Container runtime: Docker

## Safety
The intentionally vulnerable application is for local,
authorized training only.

## Projects
1. Lab setup and architecture
2. Web application security assessment
3. Security findings and remediation
4. Detection and monitoring — planned

## Results
Test results and screenshots will be added after
each exercise is completed and verified.
